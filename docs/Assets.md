# Assets du projet

**Projet :** Le Petit Prince – Une Aventure Interactive 3D

---

# 1. Objectif

Ce document recense l'ensemble des ressources (assets) utilisées dans le projet.

Il sert à :

* suivre l'avancement du contenu ;
* éviter les doublons ;
* documenter les sources ;
* contrôler la qualité ;
* faciliter le remplacement des ressources temporaires par des versions définitives.

Chaque nouvel asset devra être ajouté à ce document.

# 16. Sources des ressources

Pour chaque asset, documenter :

* auteur ;
* licence ;
* provenance ;
* date d'intégration ;
* modifications apportées.

Aucune ressource ne doit être utilisée sans licence compatible avec le projet.

---

# 17. Qualité attendue

Tous les assets doivent respecter les critères suivants :

* cohérence artistique ;
* style inspiré des aquarelles de Saint-Exupéry ;
* faible poids ;
* optimisation Web ;
* qualité professionnelle.

Les ressources temporaires devront être remplacées avant la version finale.

---

# 18. Suivi des assets

Légende :

* ⏳ À créer
* 🔄 En cours
* ✅ Terminé
* ⚠️ À remplacer
* ❌ Supprimé

Chaque modification d'un asset doit être reportée dans ce document.

---

# 19. Ressources externes recommandées

Pour accélérer le développement, privilégier des ressources provenant de bibliothèques reconnues et compatibles avec le projet, telles que :

* Poly Pizza (modèles 3D)
* Kenney Assets
* Sketchfab (avec licence appropriée)
* OpenGameArt
* AmbientCG
* Poly Haven (HDRI et textures)
* Freesound (effets sonores, sous réserve des licences)

Toute ressource importée devra être adaptée afin de conserver une identité visuelle homogène avec *Le Petit Prince*.

---

# 20. Objectif final

À la livraison du projet :

* aucun asset temporaire ne doit subsister ;
* toutes les ressources doivent être optimisées ;
* les licences doivent être vérifiées ;
* chaque asset doit être documenté dans ce fichier ;
* l'ensemble des ressources doit former un univers cohérent, poétique et fidèle à l'esprit de *Le Petit Prince*.
